# 网盘防和谐神器脚本
- by Gemini 3.1 Pro

本工具集包含4个PowerShell脚本，通过文件重命名混淆与加密压缩结合的方式，防止本地文件在上传至云盘时被系统特征码扫描、和谐或误删。

## 脚本功能说明

| 脚本名称 | 功能描述 |
| --- | --- |
| **archive_files.ps1** | 遍历指定目录及子文件夹，将每个文件独立打包为带有密码(123456)的ZIP压缩包(仅存储模式)，并在用户指定的输出目录中完美重建原始的树状目录结构。 |
| **extract_files.ps1** | 批量解压上述脚本生成的ZIP文件，自动输入密码并按相同的树状结构释放到指定的输出目录中。 |
| **rename_to_numbers.ps1** | 将当前目录下所有文件和文件夹名称替换为纯数字(保留原扩展名)，同时生成一个包含原始目录结构与名称映射记录的`index`文件夹。 |
| **restore_from_index.ps1** | 读取`index`文件夹中的映射数据，将所有数字化的文件和文件夹名称按自上而下的顺序精准还原，并在完成后自动清理`index`目录。 |

## 依赖环境

* **操作系统**：Windows (需内置PowerShell)
* **核心组件**：7-Zip (脚本默认调用路径为`C:\Program Files\7-Zip\7z.exe`，若安装在其他路径需手动修改脚本头部变量)

## 典型使用工作流

为了实现最大程度的防和谐保护，建议按以下顺序组合使用：

### 阶段一：上传前处理 (混淆与加密)

1. 将`rename_to_numbers.ps1`放入需要处理的根目录并运行，所有敏感文件与文件夹名将被数字替换。
2. 妥善备份并**单独保存**生成的`index`文件夹(切勿将其与混淆后的文件一起明文上传至同一个网盘公开目录)。
3. 在处理好的目录中运行`archive_files.ps1`，将已变成数字名称的文件批量进行ZIP加密打包，输出到新的目录。
4. 将最终生成的加密ZIP文件夹上传至网盘。

### 阶段二：下载后恢复 (解密与还原)

1. 从网盘将加密的ZIP文件夹下载至本地。
2. 将`extract_files.ps1`放入该文件夹并运行，将所有文件解压至指定的新目录。
3. 将阶段一备份的`index`文件夹完整移入解压后的根目录中。
4. 运行`restore_from_index.ps1`，所有文件和文件夹将恢复原始名称，脚本运行完毕后自动清理缓存记录。

## 注意事项

* **index文件夹是唯一还原凭证**：请务必妥善保管生成的`index`文件夹。如果丢失，被重命名的嵌套文件将极难批量找回原始名称。
* **自定义密码**：脚本中默认压缩和解压密码为`123456`。若需修改，请右键编辑`archive_files.ps1`和`extract_files.ps1`，将其中的`-p123456`替换为您需要的密码。
* **防套娃报错**：重命名和还原脚本已内置防呆设计，排除了对脚本自身及`index`目录的修改，请确保严格按照工作流的步骤存放和运行脚本。
