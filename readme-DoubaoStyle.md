# 🛡️ 网盘防和谐神器脚本

还在烦恼珍藏的资料或是辛苦整理的文件被网盘莫名其妙“咔嚓”掉吗？这套工具帮你给文件穿上一层“隐形衣”！

通过“全员数字易容”**加**“ZIP套娃加密”的双重魔法，轻松绕过网盘的特征码扫描，让你的文件平平安安上云，整整齐齐回家。

## 🧰 脚本兄弟连都有谁？

| 脚本名称 | 绝活介绍 |
| --- | --- |
| **archive_files.ps1** | **打包小能手**：顺藤摸瓜把你指定目录下的所有文件单独装进 ZIP 压缩包里，密码统一加上 `123456`（仅存储不压缩，主打一个快），并且完美复刻你原来的文件夹层级。 |
| **extract_files.ps1** | **拆包小能手**：怎么吞进去的怎么吐出来。帮你把上面打包好的 ZIP 批量解压，自动输入密码，原汁原味还原目录树。 |
| **rename_to_numbers.ps1** | **易容大师**：把当前目录下所有的文件和文件夹全改成六亲不认的纯数字（扩展名会保留）。干完活会偷偷塞给你一个叫 `index` 的文件夹，这是能变回原样的“族谱”！ |
| **restore_from_index.ps1** | **还魂法师**：拿着 `index` 里的“族谱”，从外到里把所有的数字名字全部变回最初的模样。完事后还会懂事地自动销毁 `index`，深藏功与名。 |

## 🛠️ 食用指南（建议按顺序来）

想达到最强防和谐效果？请按照下面的“伪装与撤离”两步走：

### 🎬 上半场：伪装上云（打包传网盘）

1. 把 `rename_to_numbers.ps1` 丢进你要处理的文件夹里双击运行（记得用 PowerShell 运行）。这时候你的文件全变成数字了。
2. ⚠️ **最重要的一步**：把刚刚生成的 `index` 文件夹拿出来，**单独找个安全的地方藏好**！（千万别跟你的资源一起传到网盘同一个公开目录里，不然就是掩耳盗铃了）。
3. 接着在刚才那堆数字文件里运行 `archive_files.ps1`，把它们统统变成加密 ZIP，输出到一个新文件夹里。
4. 把最终的加密 ZIP 文件夹大胆传上网盘吧！

### 🎬 下半场：安全回家（下载并还原）

1. 把网盘里的加密 ZIP 文件夹下载到本地。
2. 把 `extract_files.ps1` 丢进去运行，文件会被解压到你指定的新目录里（现在它们还是数字名字）。
3. 把上半场让你藏好的那个 `index` 文件夹，整个丢进解压好的目录里。
4. 运行 `restore_from_index.ps1`，见证奇迹的时刻！所有文件变回原样，`index` 也会自动消失，就好像什么事都没发生过一样。

## 💡 碎碎念（必看）

* ❗ **护好你的 index**：`index` 文件夹就是你的宝藏地图！要是把它弄丢了，你那堆被改成几十层嵌套数字的文件，大罗神仙来了也难帮你把名字全找回来。
* 🔑 **想换密码？**：脚本里的默认压缩/解压密码是 `123456`。觉得不够野？右键用记事本打开 `archive_files.ps1` 和 `extract_files.ps1`，把里面的 `-p123456` 改成你想要的密码就行。
* ⚙️ **运行环境**：Windows 系统自带的 PowerShell 就能跑。唯一的要求是你得装了 **7-Zip**（脚本默认去 `C:\Program Files\7-Zip\7z.exe` 找它，如果你装在别处了，记得改一下脚本第一行的路径）。
